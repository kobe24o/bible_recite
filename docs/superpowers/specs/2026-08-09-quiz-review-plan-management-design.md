# 答题判分与按计划艾宾浩斯复习管理设计

## 目标

修复答题入口、配置、判分和重复保存问题；把艾宾浩斯从全局开关改为每个背诵计划独立管理。既有背诵计划、背诵历史、答题历史和统计必须保留。

## 范围与明确规则

1. 中文答题按拼音逐字判分。答案的全部拼音必须以连续片段出现在识别文本中；识别文本可在前后有多余内容。例如目标“耶和华”可匹配“耶稣耶和华”。拼音转换及“忽略后鼻音”继续使用现有设置。
2. 答题服务地址、模型名称、API Key 任一为空即为未配置。所有答题入口均不发送模型请求，并显示“缺少答题配置”。
3. 今日任务背诵结束后，如果题目已准备好则自动进入答题；配置、网络或模型输出失败时显示明确原因，不再静默停留在背诵页。
4. 已经作答的题目保存改为幂等：不报错、不产生第二条结果；已有答题结果仍只计入一次准确率。
5. 自定义计划未选择经文时显示“请添加经文”。
6. 从经文阅读长按选择创建的计划必须可编辑日期。为该“创建→编辑日期→保存”路径增加回归测试，并修复测试复现的异常。
7. 非任何背诵计划发起的背诵不再创建艾宾浩斯周期；旧的无来源周期取消并从复习计划列表隐藏，但原背诵统计保留。

## 数据设计与迁移

### 背诵计划设置

`memorization_plan` 新增 `ebbinghaus_enabled INTEGER NOT NULL`。新建计划默认 `0`；已有计划按升级前的全局 `ebbinghaus_settings.enabled` 值初始化，保留用户升级前的总体选择。

`ebbinghaus_settings` 保留全局通过阈值；移除其作为“是否创建周期”的职责。设置页入口改为“艾宾浩斯设置”，其中展示通过阈值与所有背诵计划的独立开关。

### 复习来源

`ebbinghaus_cycle` 新增可空 `source_plan_id`，外键引用 `memorization_plan`。创建周期时取 `recitation_result.plan_id`：

- `plan_id` 非空且对应计划开关开启：创建或继续该计划的周期。
- `plan_id` 为空、计划不存在或开关关闭：不创建周期。

迁移时由 `source_result_id -> recitation_result.plan_id` 回填。回填为空的旧周期标记为取消，所有未完成复习标记为取消。计划来源的完成、失败和已暂停周期保留。

### 查询模型

新增“复习计划摘要”和“复习计划详情”查询，均以 `source_plan_id` 为分组键。摘要显示来源背诵计划名称、活动/暂停状态、经文数、待复习数和最近到期日；详情按原背诵经文范围列出每个周期的 1/2/4/7/15/30 天条目、完成状态、结果和下一次日期。

复习详情的阅读和背诵使用周期保存的开始/结束章、节，不扩大为整章。

## 页面与交互

### 我的计划

原“我的计划”拆为“我的背诵计划”和“我的复习计划（艾宾浩斯）”。背诵计划保留现有创建、编辑、暂停和再次执行能力。

复习计划条目对应一个背诵计划。暂停会暂停该来源计划全部活动周期并停止今日复习；恢复会恢复它们。“再次执行”进入该复习计划所管理经文的原精确范围背诵流程；每段重新背诵通过后，使用新的背诵结果建立一套从当天开始的 1/2/4/7/15/30 天周期。旧周期和已完成历史不改写，避免同一背诵结果重复建立周期。

### 设置

原艾宾浩斯总开关替换为设置按钮。进入设置后可调通过阈值，并为每条背诵计划切换“启用艾宾浩斯复习”。关闭计划开关立即暂停其活动周期；重新开启只恢复暂停周期，不追溯非计划背诵。

### 答题

所有入口在准备题目前先校验完整模型配置。阅读页、计划阅读页保留预生成状态和重试；今日任务在背诵完成时，对不可进入答题的原因给出提示。答题页面收到已作答题目时显示已有结果或直接忽略保存冲突，不显示数据库错误。

## 判分算法

中文答案使用现有词典和后鼻音设置将目标词与识别文本各转换为拼音序列。只要目标完整序列是识别序列的连续子序列，就判对；即最长公共连续子串长度等于目标拼音序列长度。空答案、不能转换的目标、只匹配部分目标拼音均判错。非中文保持现有严格文本判分。

## 错误处理

- 缺少配置：统一返回、显示“缺少答题配置：请填写服务地址、模型名称和 API Key”。
- 生成失败：保留服务端错误（如限流），但不让今日任务静默失败。
- 已作答保存：返回现有完成摘要而非抛出异常，且不重复插入 `quiz_result`。
- 计划编辑：显示可理解的领域错误；回归测试覆盖阅读页长按创建的计划更改日期。

## 测试与验收

- 拼音：目标完整连续匹配、多余前后字、后鼻音开关、仅部分匹配和英文严格匹配。
- 配置：地址、模型、Key 分别缺失时，三个入口均不调用模型并显示配置错误。
- 今日任务：成功时进入答题；准备失败时展示具体原因。
- 答题幂等：同题连续保存只产生一条 `quiz_result`，统计不重复。
- 计划：空自定义计划提示“请添加经文”；阅读选择创建后可更改日期并保存。
- 迁移：全局开关回填现有计划；计划来源周期被正确分组；无来源旧周期取消；既有背诵与答题统计不变。
- 复习计划：每计划开关、暂停、恢复、再次执行后通过重新背诵建立新周期、精确范围阅读/背诵、1/2/4/7/15/30 天展示。

## 非目标

- 不新增账号、云同步或“其他”复习分组。
- 不改动现有背诵计划的经文范围、已完成状态或历史统计。
- 不让非计划背诵自动加入艾宾浩斯。
