# AI 单词答题设计

## 目标与边界

在现有离线背诵功能旁新增单词答题：模型从指定经文范围挑选语义丰富、适合朗读回答的词；用户只读出一个被隐藏的词。答题复用现有离线语音识别、中文拼音纠错和“忽略后鼻音”设置。背诵准确率与答题准确率始终独立。

本功能不改变背诵计划的完成、艾宾浩斯复习或背诵结果记录规则。模型服务是可选能力；没有配置、无网络或调用失败时，现有阅读和背诵仍可用。

## 题目与缓存

一题只对应一个隐藏词，且落在一节经文中。题目保存翻译版本、书卷、章节、节号、原文 UTF-16 code-unit 的 `start`（含）和 `end`（不含）、词长、词性、简短字面解释、创建时间和作答状态。保存时必须以原文重新截取并验证 `end - start == length`；不通过的模型项不会写入。

题目缓存以“翻译版本 + 经文节”为单位复用：

- 某节仍有未作答题目时，直接复用，后续触发不再把该节发送给模型。
- 某节的已生成题目都已完成判定时，该节在下一次触发中可重新生成新题。
- 生成请求只包含需要补题的经文节；不会因重复进入页面而消耗 token。
- 同一批返回内容中，不能在同一节重复相同位置或相同词。

“已作答”定义为一次录音结束后已得到正确或错误判定；前进、后退、退出或仅查看提示不记作答。

## 三个生成入口

| 入口 | 题目范围 | 触发与进入 |
| --- | --- | --- |
| 今日任务 | 当前背诵计划的全部任务经文，保持每个任务的精确起止节 | 用户开始背诵时立即后台准备；背诵结束后自动进入答题页。 |
| 圣经阅读 | 当前打开的整章 | 页面连续停留超过 5 秒才请求；生成期间“开始答题”灰色不可点，成功后启用。 |
| 计划阅读 | 该阅读页高亮的本次背诵经文节，不扩展成整章 | 页面连续停留超过 5 秒才请求；生成完成后启用答题。 |

离开阅读页、切换章节或范围后，原 5 秒定时器取消。读取到可复用题目时可立即启用；没有题目且生成失败时显示失败原因及“重试生成”。

## 模型设置与调用

“我的”页新增“答题模型”设置：服务地址、模型名称和 API Key。默认预填智谱兼容接口地址与 `GLM-4.7-Flash`，API Key 默认空且输入遮挡。设置保存于本机 SQLite `app_setting`；密钥绝不写入源码、默认值、日志、异常文字、测试夹具、导出内容或 Git。

提供“测试连接”按钮，发出不含经文的固定 JSON 格式测试请求；成功只显示连接成功及模型名，不保存请求或返回正文。实现时开发联调可临时使用用户提供的智谱凭据，但同样不得落盘或提交。

请求输入包含经文语言版本、逐节 `reference` 和完整 `text`。模型只返回 JSON 数组，字段为：

```json
[
  {
    "reference": "约翰福音 3:16",
    "start": 0,
    "end": 2,
    "length": 2,
    "partOfSpeech": "名词",
    "meaning": "简短字面解释"
  }
]
```

提示词强制排除连词、介词、助词、语气词、标点、无完整语义的碎片；仅选择可朗读、语义丰富的词。`reference` 必须来自输入，`start/end/length` 必须精确映射回该节输入文本，不能输出 JSON 以外文字。客户端把解析、范围、长度、词性、解释非空和重复项检查作为不可信模型输出的验证边界；无效项剔除，若没有任何有效题才对该批进行一次受控重试。

## 答题体验

答题页一次显示一题：完整经文可读，目标词的位置由麦克风按钮替换。底部固定“上一题”“下一题”和“答题”按钮，横向滑动也切换题目。题目状态、提示次数和完成结果在本次会话中保留。

- 点击词位麦克风或“答题”开始录音，再次点击结束。
- 识别文本仅和隐藏词比较；中文复用拼音纠错和“忽略后鼻音”设置。
- 判定后，识别文本显示在原麦克风位置；无论对错均展示正确原词并使用绿色背景。拼音匹配正确按正确处理，并保留现有纠错呈现。
- 提示按当前题独立计数：第一次显示词的前 `x` 个字（`x` 为词长减一，至少一个字）；第二次显示词性；第三次显示本题已生成的 `meaning`，之后保持显示。

## 答题数据与统计

新增 `quiz_result`，每条记录包含题目身份、经文范围、答题时间、答题加一和正确值 0/1。提交判定采用事务：题目状态转为已答、写入结果，并更新当前/最大连续正确值。错误结果将当前连续正确清零；最大值只增不减。

“我的”页新增：答题多少道、正确多少道、答题正确率、最大连续正确多少道。所有既有“准确率”文案改为“背诵准确率”；新指标明确命名“答题准确率”。

背诵地图的总览、书卷、章节、经文节各级下钻同时聚合显示：

- 背诵准确率：继续只来自 `recitation_result` / `recitation_verse_metric`。
- 答题准确率：范围内 `quiz_result` 的正确题数除以已答题数；无记录时显示“暂无答题”。

现有成就、原始背诵次数、去重经文覆盖、背诵连续天数和背诵连续节数不被答题结果改变。

## 阅读翻章

经文阅读页可横向滑动：右滑进入同卷上一章，左滑进入同卷下一章；首章和末章不跨卷。翻章后更新标题、正文、高亮、路由和题目预生成范围。手势只在文本阅读区识别，以避免干扰垂直滚动和按钮点击。

## 错误处理与测试

测试覆盖：JSON 解析与恶意/无效下标拒绝、提示词请求构造、未答题缓存排除和已答题再生成、三入口范围、5 秒取消/触发、录音判定与后鼻音设置、答题统计/连续正确、地图各级聚合、文案改名及翻章边界。现有背诵、计划、艾宾浩斯和统计回归测试必须保持通过。
