# 自定义背诵条目与子块设计

`plan_task` 是带日期与完成状态的背诵条目；`plan_task_block` 是条目内有序、精确的经文子块。旧任务启动时迁移为一个子块，所有旧日期和完成状态保持不变。

多选经文和新建计划均支持：不拆分（默认）、按卷、按章、按节、每 N 节。默认时所有已选范围都在一条背诵条目内；按策略拆分后按经文顺序一天一条，`每 N 节` 不跨章且不跨未选空隙。

用户可将一个子块移入另一条未完成的本地背诵条目。目标条目显示为一条记录，原条目清空后删除；该天因此为空时，后续未完成日期前移并缩短计划。今日计划与详情按条目显示，启动背诵时仅连续执行所选条目的所有子块，最后一块才完成条目；测验范围始终为离散的精确子块。
